## 🚀 COMO FAZER O DEPLOY (3 PASSOS)

### 📖 Leia Primeiro:
**[DEPLOY.md](DEPLOY.md)** ← Guia completo e detalhado

### ⚡ Resumo Express:

#### PASSO 1: Setup Inicial
```bash
# Tornar executável e rodar setup
chmod +x setup.sh
./setup.sh
```

#### PASSO 2: GitHub
```bash
# Criar repo em: https://github.com/new
# Nome: whatsapp-qr-connector

# Conectar e enviar
git remote add origin https://github.com/SEU-USUARIO/whatsapp-qr-connector.git
git add .
git commit -m "🎉 Initial commit"
git push -u origin main
```

#### PASSO 3: Easypanel
1. Acesse seu Easypanel
2. **Create App** → **GitHub**
3. Selecione: **whatsapp-qr-connector**
4. Configure:
   - Build Type: **Dockerfile**
   - Port: **8010**
   - Domain: **seu-dominio.com**
5. **Deploy** 🚀

✅ **Pronto!** App no ar em < 10 minutos!

## 🆘 TROUBLESHOOTING RÁPIDO

### Problema: Script não executa
```bash
chmod +x setup.sh deploy.sh
./setup.sh
```

### Problema: Porta 8010 em uso
```bash
kill -9 $(lsof -ti:8010)
python app.py
```

### Problema: Git push rejeitado
```bash
git pull origin main
git push origin main
```

### Problema: Build do Docker falha
