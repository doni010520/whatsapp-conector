## 🚀 COMO USAR (3 PASSOS)

### **1. Extrair ZIP**
```bash
# Linux/Mac
unzip whatsapp-qr-connector.zip -d whatsapp-qr-connector
cd whatsapp-qr-connector

# Windows
# Clique com botão direito → Extrair Tudo
```

### **2. Setup Inicial**
```bash
# Tornar scripts executáveis (Linux/Mac)
chmod +x setup.sh deploy.sh

# Executar setup
./setup.sh

# Ou manualmente:
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### **3. Rodar Aplicação**
```bash
python app.py
# Acesse: http://localhost:8010
```
